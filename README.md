An original spot-the-difference game: three hand-drawn Canvas scenes (a cottage garden, a lantern night market, a lighthouse at dusk), ten hidden changes per scene, click-to-circle marking, hints, a ticking clock, and a score that rewards a sharp eye.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080 in desktop Chrome
```
